## Kurulum

1. Yukarıdaki bağlantıdan APK dosyasını indirin.
2. İndirilen dosyayı açın. Android "bilinmeyen kaynaklardan yükleme" izni isterse izin verin.
3. Kurulumu tamamlayıp uygulamayı açın.

Yeni bir sürüm yayınlandığında uygulama, açılışta sizi otomatik olarak güncellemeye yönlendirir.
